# Scene Soundtrack для SillyTavern

Расширение берёт от 5 до 10 последних сообщений активного чата, определяет тон, настроение, тему, тип сцены и её энергию. По умолчанию анализирует восемь сообщений. Для подбора сравнивает настроение и тип сцены с названиями, жанрами, тегами и описаниями треков. Плеер встроен в настройки расширения.

## Установка расширения

1. Распакуй архив. Скопируй папку `scene-soundtrack` целиком в `public/scripts/extensions/third-party` внутри папки SillyTavern. Для установки только себе положи её в `extensions` внутри своей пользовательской папки, например `data/default-user/extensions`.
2. Перезапусти SillyTavern и обнови страницу. Открой **Extensions → Scene Soundtrack**. Если панель не появилась, проверь наличие файла `manifest.json` непосредственно внутри `scene-soundtrack`.
3. Убедись, что в SillyTavern подключена модель. В режиме **Мой плейлист SoundCloud** вставь полную ссылку вида `https://soundcloud.com/имя/sets/плейлист`. Если ссылка из приложения короткая, открой её в браузере и скопируй полный адрес. Можно также вставить адрес `src` из кода Embed, если SoundCloud выдаёт его для этого плейлиста.
4. Открой чат и нажми **Подобрать**. При первом выборе запусти воспроизведение кнопкой Play в плеере. Браузер может снова потребовать нажатие после смены трека.
5. Включи **Подбирать саундтрек после ответов**, чтобы расширение обновляло выбор по мере развития сцены. При похожей сцене текущий трек остаётся, а при изменении настроения смена происходит с интервалом не менее 45 секунд. **Другой трек** переключает на следующий вариант сразу.

## Автоматический поиск по каталогу

Режимы **Звуки природы**, **Инструментал без слов** и **Песни из каталога** используют официальный API SoundCloud. Для регистрации приложения SoundCloud требует Artist Pro. Если у тебя уже есть действующие ключи приложения, используй их. [Получить ключ приложения](https://developers.soundcloud.com/docs/api/register-app)

1. Скопируй `scene-soundtrack-catalog.mjs` в папку `plugins` в корне SillyTavern. Если папки нет, создай её.
2. Установи `enableServerPlugins: true` в `config.yaml`.
3. Перед запуском SillyTavern задай `SCENE_SOUNDTRACK_CLIENT_ID` и `SCENE_SOUNDTRACK_CLIENT_SECRET` в окружении его процесса. На Windows для разового запуска можно открыть PowerShell в папке SillyTavern и выполнить:

   ```powershell
   $env:SCENE_SOUNDTRACK_CLIENT_ID = Read-Host 'SoundCloud Client ID'
   $env:SCENE_SOUNDTRACK_CLIENT_SECRET = Read-Host 'SoundCloud Client Secret' -MaskInput
   .\Start.bat
   ```

   `-MaskInput` требует PowerShell 7.2 или новее. При запуске SillyTavern через Docker или сервис задай переменные окружения в контейнере или сервисе.

4. Выбери режим и нажми **Подобрать**. Кнопка **Найти на SoundCloud** открывает поиск по настроению в браузере и работает без ключей. Режим плейлиста использует встраиваемый плеер напрямую и тоже работает без ключей.

## Как выбирается музыка

- Для анализа SillyTavern делает отдельный запрос к подключённой модели. Расширение берёт до 1 600 символов с конца каждого выбранного сообщения. Если модель облачная, эти фрагменты отправляются её провайдеру.
- В SoundCloud уходят готовые общие запросы вроде `calm instrumental` или `rain ambience`. Ключ приложения хранится на сервере. Модель получает только сообщения чата и инструкцию по классификации сцены.
- Совпадение по настроению определяется по метаданным. Если в плейлисте мало подходящих тегов, расширение предлагает ближайший вариант. В инструментальном режиме отдельные треки могут содержать вокал, если метаданные его не отмечают.
- Воспроизведение зависит от доступности трека во встроенном плеере, разрешений автора и региона. Для режима плейлиста требуется ссылка, которую открывает плеер SoundCloud. Импорт всех плейлистов аккаунта через вход в SoundCloud в этой версии не предусмотрен.
